# 🎬 MyTube — Ad-Free Video Streaming App

MyTube is a modern **video-streaming application inspired by YouTube**, designed to provide users with a clean, responsive, and enjoyable video-watching experience without advertisements.

The app allows users to discover, search, browse, and watch videos through a simple and intuitive interface.

## 🚀 Features

* 🎥 **Video Streaming** — Watch videos directly within the application
* 🔎 **Video Search** — Quickly find videos using the search functionality
* 📂 **Category Browsing** — Explore videos based on different categories
* ▶️ **Video Playback** — Smooth and convenient video playback
* 🧭 **Easy Navigation** — Simple and user-friendly navigation
* 📱 **Responsive UI** — Designed to work across different screen sizes
* 🚫 **Ad-Free Experience** — Watch videos without intrusive advertisements
* ⚡ **Fast & Lightweight** — Focused on a simple and efficient user experience

## 📱 App Overview

MyTube provides a familiar video-streaming experience while keeping the interface simple and focused on the content.

### Main Sections

* **Home** — Discover available videos
* **Search** — Search for specific videos
* **Categories** — Browse videos by category
* **Video Player** — Watch selected videos
* **Navigation** — Move easily between different sections of the app
